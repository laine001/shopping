## 购物商城 UI 迭代（Next.js 16 + App Router）

用户反馈驱动的四处修改（基于此前搭建的极简/便当盒撞色/大圆角商城）：

1. **去除首页 Banner 上方的文字分类条（chips）**：删除 `app/page.tsx` 的 chips 区块及 `globals.css` 中 `.chips/.chip` 样式；分类筛选改由金刚区承担——点击图标选中（`.icon-cell.active` 高亮），再次点击回到"全部"。
2. **扩充 feeds 数据**：`app/lib/products.ts` 从 12 件扩到 25 件（p13–p25），覆盖全部 8 个分类；`icons.tsx` 新增 speaker/camera/candle/gift/plant/bottle 六个图标。
3. **全局背景换淡色系**：Banner 由深海军蓝渐变改为奶油橘淡色渐变（文字改深色、CTA 改主色底白字、blob 降透明度）；所有商品 `gradient` 改淡色粉彩对，Product 类型新增 `fg` 字段（深色图标前景色），四处引用（ProductCard、商详大图、购物车缩略图、结算清单）均改用 `product.fg`；商品角标 `.p-tag` 改主色实底；弹窗遮罩 0.45→0.32。
4. **PC 端底栏按钮收窄**：768px+ 媒体查询中 `.action-bar-inner` 居中且 max-width 816px、按钮固定 250px 不再 flex:1 通栏；`.checkout-bar-inner` 同步收窄至 816px；移除未使用的 `.btn-navy`，补充 `.btn.disabled` 样式。

验证：`npm run build` 通过（Next 16.2.4 Turbopack，4 路由全部静态化）；curl 检查 localhost:3000 渲染确认新商品存在、chips 已移除。

注意：项目 dev 服务器常驻 3000 端口（Turbopack 热更新），再次启动会报 "Another next dev server is already running"。
